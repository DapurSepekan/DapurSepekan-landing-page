# Folder Assets — Dapur Sepekan

Letakkan semua file gambar dan logo di folder ini.

## File yang Dibutuhkan

| Nama File | Ukuran Disarankan | Keterangan |
|-----------|-------------------|------------|
| `logo-dapur-sepekan.png` | Bebas (tinggi ±40px) | Logo utama — PNG transparan |
| `favicon.png` | 64×64 px | Ikon di tab browser |
| `hero-food.jpg` | 800×600 px | Foto makanan di halaman utama |
| `family-meal.jpg` | 400×300 px | Foto untuk Family Package |
| `single-meal.jpg` | 400×300 px | Foto untuk Single Package |
| `chilled-food.jpg` | 600×400 px | Foto format Chilled |
| `frozen-food.jpg` | 600×400 px | Foto format Frozen |

## Tips Gambar

- Gunakan foto makanan rumahan berkualitas tinggi
- Format JPG untuk foto, PNG untuk logo (dengan background transparan)
- Kompres gambar sebelum upload agar website lebih cepat: https://squoosh.app
- Sumber foto gratis berkualitas tinggi: https://unsplash.com (cari "home cooking", "family meal")

## Jika File Belum Ada

Tidak masalah! Website akan menampilkan placeholder otomatis.
Kamu bisa menambahkan gambar kapan saja, lalu refresh browser untuk melihat hasilnya.
